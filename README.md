# Hands-Off Voice Prompt System for AI (Antigravity) 🎙️🤖

Это полностью автономный голосовой интерфейс, позволяющий управлять AI-ассистентами (например, Antigravity) исключительно голосом, не прикасаясь к клавиатуре и мыши.

## 🔥 Фичи
- **100% Оффлайн и Бесплатно**: Использует локальные нейросети (`faster-whisper`), никаких платных API ключей.
- **Оффлайн Озвучка**: Ответы ассистента зачитываются вслух с помощью встроенного в Windows движка (`pyttsx3`), обходя любые блокировки и ошибки.
- **Умный фильтр кода**: Не зачитывает по буквам длинные блоки кода, заменяя их на короткую фразу «[Тут написан код]».
- **Мгновенное прерывание**: Произнесите кодовое слово («Ассистент») прямо во время ответа, и ассистент мгновенно замолчит, чтобы выслушать новую команду.
- **Визуальный индикатор**: Маленькая ненавязчивая точка поверх всех окон показывает текущий статус (🟢 Слушаю / 🔴 Думаю / 🔵 Говорю).
- **Защита от галлюцинаций**: Умная калибровка микрофона на старте и фильтрация типичных галлюцинаций Whisper.

## 🛠 Установка
1. Установите Python 3.9+
2. Установите необходимые библиотеки:
   ```bash
   pip install faster-whisper SpeechRecognition pyaudio pygame pyttsx3 pyperclip pywin32
   ```
3. Запустите скрипт:
   ```bash
   python voice_bridge.py
   ```

## 🎮 Использование
1. При запуске скрипта **помолчите 2 секунды** — скрипт калибрует идеальный порог громкости для вашей комнаты.
2. В правом нижнем углу экрана появится **зеленая точка**.
3. Просто скажите: *"Ассистент, напиши простой калькулятор на Python"*.
4. Скрипт сам найдет окно приложения, вставит текст в строку ввода и нажмет Enter!

## ⚠️ Требования
- ОС: Windows (из-за использования `pywin32` для интеграции с окнами).
- Наличие установленного приложения Antigravity (поиск окна осуществляется по процессу).
